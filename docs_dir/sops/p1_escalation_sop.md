# P1 Incident Escalation SOP

## P1 Definition
An incident is classified as P1 when a critical
customer-facing service is unavailable or a major
business function is significantly impacted.

## Examples
- Customer checkout unavailable
- Payment processing unavailable
- Authentication unavailable for most users

## Procedure
1. Create a P1 incident ticket.
2. Record the affected service.
3. Record observed symptoms.
4. Attach investigation evidence.
5. Notify the incident owner.
6. Escalate unresolved incidents.

## Safety
Production-changing actions require human approval.
