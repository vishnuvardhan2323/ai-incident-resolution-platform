# VPN Connectivity Runbook

## Symptoms
- Employee cannot connect to VPN
- Authentication failure
- VPN connection timeout
- Internal applications unavailable

## Investigation Steps
1. Verify employee account status.
2. Check VPN service health.
3. Verify network connectivity.
4. Check authentication logs.
5. Verify employee VPN access.
6. Check for known VPN incidents.

## Common Causes
- Invalid credentials
- Expired password
- VPN service outage
- Missing VPN permission
- Local network connectivity issue
